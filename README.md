# আল আহসান ফাউন্ডেশন বাংলাদেশ (Al-Ahsan Foundation Bangladesh)

আল আহসান ফাউন্ডেশন বাংলাদেশ একটি অলাভজনক ও অরাজনৈতিক মানবকল্যাণমূলক সংস্থা। সমাজের সুবিধাবঞ্চিত, অসহায় ও দরিদ্র মানুষের জীবনমান উন্নয়ন, শিক্ষা, স্বাস্থ্যসেবা ও পুনর্বাসনে নিবেদিত।

## প্রযুক্তি
- **Next.js 15 (App Router)**
- **React 19**
- **Tailwind CSS v4**
- **TypeScript**

## ইনস্টলেশন ও চালনা
```bash
cd package
npm install
npm run dev
```
